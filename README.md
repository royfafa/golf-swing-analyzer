# 스윙 분석기 (golf-swing-analyzer)

스마트폰으로 찍은 골프 스윙 영상을 **브라우저 안에서** 분석하는 정적 웹앱(PWA)입니다.
영상은 서버로 전송되지 않으며, 설치·로그인·백엔드 없이 GitHub Pages 등에서 바로 열립니다.

## 1단계 기능

| 흐름 | 내용 |
|---|---|
| 1. 업로드 | 휴대폰 기본 카메라(60fps 또는 슬로모션)로 찍은 영상을 갤러리에서 선택 (앱 내 촬영 없음) |
| 2. 촬영 정보 | 촬영 방향(정면/후방, 필수), 촬영 모드(일반/슬로모션), 파일 fps, 슬로모션 촬영 속도(120/240)·파일 형태(자동/원본 고프레임/느리게 재생됨) |
| 3. 트림(필수) | 실제 시간 약 2~3초(최대 6초)만 남김 |
| 4. 자세 분석 | MediaPipe Pose로 **실제 시간 기준 최대 30fps** 샘플링, 진행률·중단 버튼, 이동 대기 500ms 타임아웃 |
| 5. 구간 확정 | 어드레스·탑·임팩트·피니시 자동 **제안** → 원본 1프레임 단위로 옮겨 사용자가 확정 |
| 6. 결과·저장 | 촬영 방향별 지표 + 4구간 스냅샷(JPG). IndexedDB에 **수치 JSON + 스냅샷만** 저장(원본 영상 저장 안 함) |

### 촬영 방향별 지표
- **정면(Face-on)**: 템포, 머리 좌우·상하 이동, 골반·상체 스웨이 — 이동량은 **추정 신장 대비 %**
- **후방(Down-the-line)**: 템포, 척추 전경각(어드레스 기준 변화) — 팔·어깨 가림 시 "신뢰도 낮음" 표시
- 템포는 **비율(배율 무관)** 과 **절대 시간(배율 의존)** 을 분리해 표시

### 제공하지 않는 것
비거리·구질 예측은 휴대폰 1대 영상으로는 페이스 각도·스핀·3차원 출발 방향을 측정할 수 없어 제공하지 않습니다.

## 진단 정보 (실기기 검증용)
분석 화면 하단에 항상 표시됩니다.
- 컨테이너(MP4/MOV `stts`)에서 읽은 대표·평균·최소~최대 fps, **가변 프레임레이트(VFR) 여부**, 편집 목록 재생 속도
- 재생 기반 추정 fps(컨테이너를 못 읽을 때의 참고값), 선택 fps, 시간 배율, 실제 시간 환산 길이
- 샘플 간격, 트림 구간, 자세 인식 엔진(모델·GPU/CPU), **분석 처리 속도(fps)**, 인식률, 이동 타임아웃 횟수, 브라우저 정보

## 파일 구조
```
index.html            화면
styles.css            스타일(라이트/다크)
manifest.webmanifest  PWA 매니페스트
js/app.js             화면 흐름·상태
js/timebase.js        촬영 모드별 시간 환산·샘플링 간격 (순수 함수)
js/mp4meta.js         MP4/MOV moov 파싱 → 정확한 fps·VFR 판별
js/video.js           타임아웃 있는 프레임 이동, 이동 큐, iOS 디코더 깨우기
js/pose.js            MediaPipe Pose Landmarker 로딩·추론 (GPU 실패 시 CPU)
js/analyze.js         트림 구간 샘플링 분석 루프
js/series.js          시계열 유틸 (순수 함수)
js/phases.js          4구간 자동 제안 (순수 함수)
js/metrics.js         방향별 지표 계산 (순수 함수)
js/render.js          골격·손 궤적 오버레이
js/store.js           IndexedDB 기록 저장
tests/                Node 단위 테스트 (+ ffmpeg로 만든 작은 영상 fixture)
```

## 실행
```bash
python3 -m http.server 8000   # 아무 정적 서버
# http://localhost:8000 접속 (카메라 없이도 동작, ES 모듈이라 file:// 로는 열리지 않음)
npm test                      # Node 22+ 단위 테스트
```

외부 리소스: MediaPipe tasks-vision 1.2.2(jsDelivr), 포즈 모델(storage.googleapis.com), Pretendard 폰트(jsDelivr).
